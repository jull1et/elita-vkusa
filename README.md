# Шаблон сайта-меню для выездного повара / кейтеринга

Готовый одностраничный сайт: первый экран с фото, цифры, «что входит», меню с выбором блюд, галерея, как проходит заказ,
форма заявки, которая уходит в WhatsApp готовым текстом. Цен нет: «стоимость обсудим в WhatsApp».
Сделан для шефа Дмитрия (https://jull1et.github.io/dmitry-catering/), от него и скопирован. Работает на телефоне (375 px) и компьютере.

## Как сделать новый сайт (по шагам)
1. **Копия:** `cp -R ~/projects/chef-site-template ~/projects/<имя-повара>-site` (без `.git`, `.venv` можно не копировать, он тяжёлый: создать заново см. «Инструменты»).
2. **site.json:** заменить все значения на данные нового повара (бренд, телефон `phone_owner` в формате 77XXXXXXXXX, Instagram, город, цифры `stats`, что входит `included`, меню `menu`, форматы мероприятий `formats`, подписи фото). Ключ `repo` = `jull1et/<имя-репозитория>`, `site_url` = адрес на github.io, `demo: true` пока макет не оплачен.
3. **Фото:** положить свои (или бесплатные стоки с Pexels) в `photos/` под именами из шапки `optimize_images.py`, запустить `./.venv/bin/python optimize_images.py`. Реальные фото повара лучше стоков.
4. **Иконки** нужны другие? Phosphor: `curl -o icons/<имя>.svg https://unpkg.com/@phosphor-icons/core@2.1.1/assets/regular/<имя>.svg`.
5. **Шрифты** (если в тексте казахские буквы): `subset_fonts.py`.
6. **Репозиторий:** `git init -b main`, создать публичный репозиторий `jull1et/<имя>` (gh залогинен как jull1et), включить GitHub Pages (ветка main, корень). Коммиты от **jull1et** с noreply-почтой (`git -c user.name=jull1et -c user.email=336166279+jull1et@users.noreply.github.com commit`), не от глобального git-юзера.
7. **Публикация строго в таком порядке** (из-за CDN): сначала закоммитить и запушить `img/` и `fonts/`, потом `python3 build.py`, потом закоммитить и запушить `index.html`.
8. **Проверка до отправки ссылки:** открыть на 375 px и на 1500 px, пройти весь путь клиента (выбрать блюда, заполнить форму, посмотреть ссылку WhatsApp БЕЗ отправки), консоль без ошибок, нет горизонтальной прокрутки, первый экран влезает с кнопкой.
9. **Ссылку давать с добавкой `?v=N`** (обход кэша GitHub Pages, он держит страницу 10 минут). После публикации подождать, пока файл появится на сайте (curl), и только потом писать «готово».

## Режимы
- `"demo": true` (по умолчанию для нового клиента): сверху тёмная плашка «Макет сайта. Создан <автор>», все ссылки WhatsApp и форма ведут на автора (`phone_author`), номер повара виден, но не кликабелен, сайт закрыт от поисковиков.
- Когда повар купил: `"demo": false`, удалить из `index.tpl.html` блок `<div class="demo">`, стили `.demo` и `calc(100svh - 40px)` у `.hero` (вернуть `100svh`), `python3 build.py`, пуш.

## Что НЕ делаем
- Не придумываем отзывы и «наши работы» из стоков: галерея стоковых фото подписана «Так может выглядеть ваш стол» + «Фото для примера». Блока отзывов нет, пока нет настоящих.
- Не отправляем сообщения повару/клиентам без явной просьбы Юлии. Тестовую заявку не отправлять.
- Не используем длинное тире в текстах (build.py печатает предупреждение).

## Известные грабли (уже решены в шаблоне)
- GitHub Pages у Юлии очень медленный (3-20 КБ/с): фото и шрифты отдаются с CDN jsDelivr, в `build.py` закреплены за коммитом, запасной вариант локальные файлы.
- iOS Safari: поля даты/времени вылезали (теперь `.pick` с подсказкой), высота первого экрана считается один раз (`--hh`), иначе фото «прыгает», когда панели браузера прячутся.
- Не использовать `position:absolute` у `picture` без явных стилей `img` (фото вылезало на весь сайт).
- Выбранное блюдо: кнопка меняется на тёмную с галочкой (иконка `check` всегда включена в спрайт).
- Фото над меню одно и то же для всех разделов (смена картинки мигала).

## Инструменты (для фото и шрифтов)
```
python3 -m venv .venv && ./.venv/bin/python -m pip install -U pip && ./.venv/bin/pip install --only-binary=:all: pillow fonttools brotli
```
(на этом Mac старый pip не видит колёса, поэтому сначала обновить pip.)

## Файлы
`index.tpl.html` разметка и стили с токенами `{{...}}` · `site.json` все тексты и меню · `build.py` сборка · `optimize_images.py` фото · `subset_fonts.py` шрифты · `img/`, `lqip.json`, `fonts/`, `icons/` ресурсы · `photos/` исходные фото (сейчас стоки Pexels из сайта Дмитрия).
